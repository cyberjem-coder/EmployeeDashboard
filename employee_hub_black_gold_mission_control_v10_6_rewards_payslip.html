This is a local UI gate, not server-grade authentication. Sensitive manager, payroll, and notes views auto-lock after 15 minutes of inactivity.
Hosted cloud mode uses an authenticated Google-account allowlist for cloud snapshot access and server writes. Employee PINs and the on-screen manager, payroll and notes PIN gates remain local to each browser; they are not a substitute for a dedicated server-side employee login. Spreadsheet editors can still alter sheet records and audit rows. Use a properly secured backend and independent payroll review for production statutory payroll.
Privacy and security: a standalone HTML file cannot enforce tamper-proof audit logs or keep PINs secret from someone who can inspect browser storage or edit the file. Use a server-backed system for production payroll, legal records, and multi-device access.
