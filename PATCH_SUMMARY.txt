PATCH SUMMARY — EMPLOYEE HUB V10.15 NETLIFY DASHBOARD REPAIR
=============================================================

ROOT CAUSES ADDRESSED
---------------------
1. The Netlify package had only an Owner Authorization endpoint. The dashboard
   itself still called google.script.run for cloud and admin operations, but
   static Netlify pages do not provide google.script.run.
2. The task-evidence module had been inserted inside the payslip print HTML
   template. This broke the main dashboard script block and prevented the main
   JavaScript from loading correctly. The module is now a separate script again.
3. The Netlify owner endpoint compared against a duplicate OWNER_PASSWORD
   environment variable. That could become stale when the password changed in
   Apps Script. Owner password verification now remains server-side in Apps
   Script.

ADDITIVE CORRECTIONS
--------------------
- Added netlify/functions/employee-hub-api.js with an allowlist of existing
  Employee Hub server operations.
- Added a Netlify-only google.script.run compatibility layer in Index.html.
  Native Apps Script google.script.run remains intact in the separate HTML.
- Connected cloud revision, snapshot load/save, archive batches, evidence
  upload, owner password changes, authorized computer listing and revocation.
- Added chunked Drive evidence upload. Existing 10 MB photo and 20 MB video
  limits are retained.
- Refreshes the cloud revision after a computer is authorized, reducing
  revision-conflict failures on the first save.
- Updated setup instructions and added a test report.

PRESERVATION

- Original employee, attendance, payroll, task, evidence, archive, audit,
  payroll export, quarterly reporting, motivator, and security features remain.
- Existing spreadsheet tabs, records, employee PINs, and password hashes are
  not changed by preparing this ZIP.
- The original Apps Script-hosted HTML mode is retained.

VALIDATION

- Live Netlify, Apps Script deployment, Google Sheets, and Drive integration
