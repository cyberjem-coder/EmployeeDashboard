EMPLOYEE HUB V10.15 — START HERE
================================

This package contains the Netlify Owner Authorization Bridge fix.

IMPORTANT:
Use NETLIFY_OWNER_PASSWORD_SETUP_README.txt as the current setup guide.
That guide supersedes earlier instructions in this package that said the
static Netlify site could not use Owner Security.

The Owner Password has already been created in the bound Apps Script project.
For the Netlify flow, the Netlify OWNER_PASSWORD environment variable must
contain exactly the same password.

The Apps Script backend also needs the HUB_NETLIFY_BRIDGE_SECRET Script
Property and a new Web App deployment version after the backend code is
updated. Follow the current setup guide one step at a time.

Do not delete spreadsheet tabs, employee records, or existing dashboard
features. Back up Code.gs before updating it.
